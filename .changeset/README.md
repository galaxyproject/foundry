# Changesets

Hi! This directory has been automatically generated by `@changesets/cli`. Add a markdown file describing each user-facing change to packages under `packages/`. See https://github.com/changesets/changesets for details.

Foundry-internal scripts (under `scripts/`) and content (`content/`, `docs/`, `casts/`) are not versioned and don't need changeset entries.

Private workspace packages, including `foundry-site`, are excluded from versioning and don't need changeset entries. Changes to published packages under `packages/` still require a changeset.
